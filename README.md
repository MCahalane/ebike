# E-Bike Shop: This project is a simple web program for an E-Bike Shop. It is created using HTML, CSS, and JavaScript. The website allows users to view a homepage with information about the shop and click a button to view different types of e-bikes, including City E-Bikes, Mountain E-Bikes, and Commuter E-Bikes. CSS is used to style the website with a green colour theme, while JavaScript is used to make the buttons work and navigate between the pages.

# Task 1 – Create the Homepage

Create an HTML webpage for an E-Bike Shop. Add a main heading that welcomes users to the shop and include a short paragraph explaining that the website allows users to explore electric bikes.

# Task 2 – Add a Navigation Button

Add a button called “View E-Bikes” to the homepage. The button should allow the user to navigate to another webpage where they can see the available e-bikes.

# Task 3 – Create the E-Bike Page

Create a second HTML webpage called Ebike.html. Add information about at least three different types of e-bikes, such as a City E-Bike, Mountain E-Bike, and Commuter E-Bike. Include a heading and a short description for each bike.

# Task 4 – Style the Website

Create a CSS file called style.css and use it to style both webpages. Add a background colour, change the colours of the headings, adjust the font size, centre the content, and style the buttons.

# Task 5 – Add a Hover Effect

Use CSS to create a hover effect for the buttons. The appearance of the button should change when the user moves their mouse over it.

# Task 6 – Add JavaScript

Create a JavaScript file called script.js. Use JavaScript to make the “View E-Bikes” button take the user from the homepage to Ebike.html.

# Task 7 – Add a Back Button

On the E-Bike page, create a “Back to Home” button. Make the button return the user to index.html when clicked.

# Task 8 – Test Your Website

Open the website in a web browser and test all buttons and links. Make sure the homepage loads correctly, the E-Bike page opens when the button is clicked, and the Back to Home button returns to the homepage.
